# SafeVision

نظام ذكي للتحقق من معدات السلامة في مواقع البناء باستخدام الذكاء الاصطناعي ومعالجة الصور.

## الوصف

يقوم المستخدم برفع صورة لعامل في موقع البناء، ثم يحللها النظام باستخدام Computer Vision للتعرف على معدات السلامة، ويحسب Safety Score، ويعرض تقريراً مفصلاً.

## المميزات

- كشف تلقائي لمعدات السلامة (خوذة، سترة، قفازات، حذاء، نظارات)
- حساب Safety Score تلقائياً
- عرض تقرير مفصل بالمعدات الموجودة والمفقودة
- واجهة ويب بسيطة وسهلة الاستخدام

## التقنيات المستخدمة

- YOLOv8 (Object Detection)
- Python + Flask
- OpenCV + PyTorch

## طريقة التشغيل

1. تثبيت المكتبات: pip install -r requirements.txt
2. تدريب النموذج: python train.py
3. تشغيل الموقع: python app.py
4. فتح المتصفح على: http://localhost:5000

## ملاحظة

النظام أداة مساعدة وتوعوية، وليس بديلاً عن مسؤول السلامة أو إجراءات السلامة الرسمية في موقع البناء.
